# CITIZENS ARCHIVE

A lightweight, local-first intelligence research workspace for organizing **authorized** open-source research: cases, public sources, notes, entities, timelines, and relationship graphs.

## Features

- Dark charcoal and deep-red intelligence-dashboard interface
- Collapsible sidebar and responsive mobile/desktop layout
- Dashboard statistics, recent activity, and quick-access tools
- Case creation, renaming, editing, deletion, labels, descriptions, and notes
- Draggable and resizable information cards
- Card relationship links and an interactive knowledge graph
- Draggable graph nodes, zoom/pan controls, and node inspection
- Public-source archive with verification labels and collection dates
- Editable chronological timeline with record links
- Local search across cases, cards, sources, and timeline events
- JSON, CSV, TXT, and HTML export; JSON import; print-friendly reports
- Browser `localStorage` persistence; no account or backend required

## GitHub Pages

1. Push or commit these files to the repository’s `main` branch.
2. In GitHub, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select `main` and `/ (root)`, then save.
5. Open the published URL.

## Privacy and acceptable use

This tool is intended only for information you are authorized to collect and organize. It does not provide breach-dump browsing, credential search, or functionality for stolen credentials, private addresses, or private phone numbers.

All data remains in your browser’s local storage. Clearing browser data or using a private window can erase it; use **Export Center → JSON Archive** for backups.

## Search scope

Search operates only on information already stored locally in CITIZENS ARCHIVE. It does not perform live internet searches or generate fabricated results.
